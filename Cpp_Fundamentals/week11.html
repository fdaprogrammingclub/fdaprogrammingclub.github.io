Problem 2: Trapezoid Area

Functions | Real numbers | Arithmetic

Problem

A trapezoid has two parallel sides (the bases) of lengths a and b, and the distance between the bases (the height) is h. Compute the area of the trapezoid:

S = (a + b) * h / 2

Function to implement

double calculateTrapezoidArea(double a, double b, double h);

The function takes the two bases and the height, and returns the area as a double.

Input

Three real numbers a, b, h separated by spaces: the two bases and the height.

Output

The area of the trapezoid, printed with exactly two digits after the decimal point. Formatting is already handled by main().

Constraints

  • 0 < a, b, h <= 10^6

Examples

Input
3 5 4
Output
16.00

S = (3 + 5) * 4 / 2 = 16.

Input
2.5 4.5 3
Output
10.50

S = (2.5 + 4.5) * 3 / 2 = 10.5.

Input
10 10 10
Output
100.00

Equal bases: the trapezoid is a parallelogram and S = 10 * 10 = 100.

Requirements

  • The return type must be double.
  • Use real-number division (divide by 2.0, or multiply by 0.5); do not use integer division.
  • Do not print anything inside the function.
  • Do not modify main().

Provided code

#include <iomanip>
using namespace std;

    // Your code here
}

int main() {

    cin >> a >> b >> h;

Problem 3: Update Balance

Functions | Local variables | Pass by reference | Rounding

Problem

A bank account uses VND. Its balance is stored in a variable balance (type long long), initially equal to 0. The variable must be declared locally in main(), not as a global variable.

The user performs T operations in order. Each operation is one of:

  • Deposit (1 x y): deposit x USD at an exchange rate of y VND/USD. The balance increases by x * y VND, rounded to the nearest VND.
  • Withdrawal (2 z): withdraw z VND.
    • If balance >= z, decrease the balance by z.
    • Otherwise, print Insufficient balance! on its own line and leave the balance unchanged.

After every operation, main() prints the current balance. For a failed withdrawal, the message Insufficient balance! therefore appears on the line before the balance line.

Functions to implement

void update(long long& balance, double x, double y);
void withdraw(long long& balance, long long z);

Both functions receive balance by reference, allowing them to modify the original variable. You may add #include <cmath> if you need a rounding function.

Input

  • Line 1: an integer T, the number of operations.
  • Each of the next T lines is either 1 x y (deposit) or 2 z (withdrawal).

Output

After each operation, print Balance: <value> VND. If a withdrawal fails, print Insufficient balance! before that line.

Constraints

  • 1 <= T <= 1000
  • 0 <= x <= 10^6
  • 0 < y <= 10^6
  • 0 <= z <= 10^15

Example

Input
5
1 100 25400
2 1000000
1 20 25000
2 3000000
2 500000
Output
Balance: 2540000 VND
Balance: 1540000 VND
Balance: 2040000 VND
Insufficient balance!
Balance: 2040000 VND
Balance: 1540000 VND

Requirements

  • Declare balance as a local variable in main(), initialized to 0. Do not use a global variable to store the balance.
  • Pass balance by reference to both functions.
  • Only withdraw() prints the failure message; update() prints nothing.
  • Do not modify the function names or parameter types.

Provided code

#include <iostream>
using namespace std;

void update(long long& balance, double x, double y) {
    // TODO
}

void withdraw(long long& balance, long long z) {
    // TODO
}

int main() {
    long long balance = 0;
    int T;
    cin >> T;

    while (T--) {
        int type;
        cin >> type;

        if (type == 1) {
            double x, y;
            cin >> x >> y;
            update(balance, x, y);
        } else if (type == 2) {
            long long z;
            cin >> z;
            withdraw(balance, z);
        }

        cout << "Balance: " << balance << " VND" << endl;
    }

    return 0;
}

Problem 4: String Editor with Reference Parameters

Functions | Local variables | Pass by reference | Strings

Problem

A text editor stores a string s, initially empty. The string must be declared as a local variable in main(), not as a global variable. You must process n operations in order. Each operation is one of the following:

  • Append (1 c): append character c to the end of s.
  • Replace (2 x y): replace every occurrence of character x in s with character y.

Implement the two functions below. Each function receives s by reference so that it can modify the original string.

Functions to implement

void appendCharacter(string& s, char c);
void replaceCharacter(string& s, char oldChar, char newChar);

The functions do not return a value. The string must be passed by reference, not copied.

Input

  • The first line contains an integer n, the number of operations.
  • Each of the next n lines describes one operation: 1 c or 2 x y.

Output

Print the final string s after all operations. If s is empty, print an empty line.

Constraints

  • 1 <= n <= 1000
  • c, x, and y are lowercase English letters (a-z).

Example

Input
6
1 a
1 b
1 a
2 a c
1 d
2 b e
Output
cecd

The string changes as follows: a → ab → aba → cbc → cbcd → cecd.

Requirements

  • Declare string s = ""; as a local variable in main(). Do not use a global variable to store the string.
  • Pass s by reference to both functions.
  • Both functions must have return type void.
  • Do not modify the function names or parameter types.

Provided code

#include <iostream>
#include <string>
using namespace std;

string s = "";

void appendCharacter(char c) {
    // Your code here
}

void replaceCharacter(char oldChar, char newChar) {
    // Your code here
}

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        int type;
        cin >> type;

        if (type == 1) {
            char c;
            cin >> c;
            appendCharacter(s, c);
        } else {
            char x, y;
            cin >> x >> y;
            replaceCharacter(s, x, y);
        }
    }

    cout << s << '\n';
    return 0;
}

Problem 5: RSA Lite: Key Validation

Number theory | Primes | GCD

Problem

RSA is a public-key cryptosystem based on number theory. In this exercise you validate a simplified RSA key.

You are given integers p, q, e. The numbers p and q must both be prime. Define

n = p * q,    phi(n) = (p - 1)(q - 1)

The key is valid if and only if all of the following hold:

  • p is prime and q is prime;
  • 1 < e < phi(n);
  • gcd(e, phi(n)) = 1.

Functions to implement

bool isPrime(long long n);
bool isValidExponent(long long e, long long phi);
  • isPrime(n) returns true if n is prime. Test divisors directly; do not use a sieve.
  • isValidExponent(e, phi) returns true if 1 < e < phi and gcd(e, phi) == 1. Use std::gcd() from <numeric>.

Input

One line with three integers p, q, e separated by spaces.

Output

Print VALID if the key is valid, otherwise INVALID.

Constraints

  • 2 <= p, q <= 10^6 (not guaranteed to be prime)
  • 1 <= e <= 10^12

Examples

Input
5 11 3
Output
VALID

phi(n) = 4 * 10 = 40. Since 1 < 3 < 40 and gcd(3, 40) = 1, the exponent is valid.

Input
5 11 10
Output
INVALID

gcd(10, 40) = 10 != 1.

Input
7 13 72
Output
INVALID

phi(n) = 6 * 12 = 72, and e must be strictly less than 72.

Input
8 11 3
Output
INVALID

8 is not prime.

Requirements

  • Implement both isPrime() and isValidExponent().
  • Use gcd() from <numeric>; do not write your own GCD.
  • Do not use a prime sieve.
  • Do not print anything inside the functions.
  • Do not modify main().

Provided code

#include <iostream>
#include <numeric>
using namespace std;

bool isPrime(long long n) {
    // Your code here
}

bool isValidExponent(long long e, long long phi) {
    // Your code here
}

int main() {
    long long p, q, e;
    cin >> p >> q >> e;

    if (!isPrime(p) || !isPrime(q)) {
        cout << "INVALID\n";
        return 0;
    }

    long long phi = (p - 1) * (q - 1);

    if (isValidExponent(e, phi)) {
        cout << "VALID\n";
    } else {
        cout << "INVALID\n";
    }

    return 0;
}

Notes

  • Compile with C++17 or later to use std::gcd().
  • Use long long for all computations involving phi(n); it can reach about 10^12.
  • In isPrime(), try divisors i from 2 while i * i <= n. Remember that numbers less than 2 are not prime.
